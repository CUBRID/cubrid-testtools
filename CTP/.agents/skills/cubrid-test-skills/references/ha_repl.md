# HA Replication Test Cases

Complete reference for HA Replication (HA_repl) test cases in CUBRID CTP.

## CTP Implementation Details

HA replication test execution is handled by the ha_repl framework:
- **Entry point**: `CTP/ha_repl/src/com/navercorp/cubridqa/ha_repl/Main.java`
- **Test orchestration**: `CTP/ha_repl/src/com/navercorp/cubridqa/ha_repl/Test.java`
- **HA instance management**: `CTP/ha_repl/src/com/navercorp/cubridqa/ha_repl/InstanceManager.java`
- **SQL migration**: `CTP/ha_repl/src/com/navercorp/cubridqa/ha_repl/migrate/SQLFileReader.java`
- **Data consistency**: `CTP/ha_repl/src/com/navercorp/cubridqa/ha_repl/CheckDiff.java`

## File Structure

```
test_directory/
├── test_name.sql      (source SQL - you write this)
├── test_name.test     (generated by CTP)
├── test_name.master.dump    (master results)
└── test_name.slave1.dump    (slave results)
```

## HA Replication Test Case Template

HA_repl test cases are **converted from SQL test cases**. The `.test` file is generated by CTP from `.sql` files.

### Original SQL (test_name.sql) - Write This

```sql
DROP TABLE IF EXISTS t1;
CREATE TABLE t1 (id INT PRIMARY KEY, name VARCHAR(100));
INSERT INTO t1 VALUES (1, 'test1');
INSERT INTO t1 VALUES (2, 'test2');
SELECT * FROM t1 ORDER BY id;
DROP TABLE IF EXISTS t1;
```

### Converted .test file (auto-generated by CTP)

```
--test:
DROP TABLE IF EXISTS t1;
--check:
@HC_CHECK_FOR_EACH_STATEMENT
--test:
CREATE TABLE t1 (id INT PRIMARY KEY, name VARCHAR(100));
--check:
@HC_CHECK_FOR_EACH_STATEMENT
--test:
INSERT INTO t1 VALUES (1, 'test1');
--check:
$HC_CHECK_FOR_DML
--test:
INSERT INTO t1 VALUES (2, 'test2');
--check:
$HC_CHECK_FOR_DML
--test:
drop table t1;
--check:
@HC_CHECK_FOR_EACH_STATEMENT
--test:
```

## HA Replication Conventions

1. **Test cases are auto-converted** from SQL files - you write `.sql`, CTP creates `.test`
2. **Most SELECT statements are removed** during conversion (special cases exist)
3. **PRIMARY KEY is auto-added** if table lacks one (required for HA)
4. **Annotations control execution:**
   - `--test:` - Execute on master only
   - `--check:` - Execute on both master and slave, compare results

## HA Check Macros

| Macro | Description |
|-------|-------------|
| `@HC_CHECK_FOR_EACH_STATEMENT` | Check catalog consistency after DDL |
| `$HC_CHECK_FOR_DML` | Check data consistency after DML |
| `$HOLDCAS_ON` | Hold CAS connection |

## Execution Commands

| Action | Command |
|--------|---------|
| Run HA Replication tests | `ctp.sh ha_repl -c conf/ha_repl.conf` |
| Check HA status | View `.master.dump` and `.slave1.dump` files |

## Result Analysis

### Test Results Location
- **Runtime logs**: `CTP/result/ha_repl/current_runtime_logs/`
- **Master dump**: `*.master.dump` (generated near scenario/test files)
- **Slave dump**: `*.slave1.dump` (generated near scenario/test files)
- **SQL source**: `*.sql`
- **Generated test**: `*.test`

### Comparing Results
```bash
# Compare master and slave results
diff test_name.master.dump test_name.slave1.dump

# If results differ legitimately, create diff file
diff test_name.master.dump test_name.slave1.dump > test_name.master.slave1.diff_1
```

### Understanding Output
- **.sql file**: Your original SQL test case
- **.test file**: Auto-generated test with HA annotations
- **.master.dump**: Results from master node
- **.slave1.dump**: Results from slave node
- **.diff_1**: Legitimate differences (if any)

## Creating Diff Files

If master and slave results differ legitimately (design or NOT-FIXED bugs):

```bash
diff test_name.master.dump test_name.slave1.dump > test_name.master.slave1.diff_1
```

The diff file will be applied during result comparison to suppress known differences.

## Configuration

- **Default config**: `CTP/conf/ha_repl.conf`
- **HA nodes**: `env.instance1.master.ssh.host`, `env.instance1.slave.ssh.host`
- **Test interface**: `test_interface_type=jdbc` (recommended)
- **SQL source**: `scenario=${HOME}/cubrid-testcases/sql`
- **Diff support**: `testcase_additional_answer = diff_1`

### Common Config Parameters
```ini
[common]
scenario = ${HOME}/cubrid-testcases/sql
testcase_additional_answer = diff_1
test_interface_type = jdbc

# HA nodes
env.instance1.master.ssh.host = 192.168.1.100
env.instance1.master.ssh.user = ha_repl
env.instance1.slave.ssh.host = 192.168.1.101
env.instance1.slave.ssh.user = ha_repl
```

## CTP-Specific Notes

- **Transforms SQL**: Applies `--test:` and `--check:` transformations
- **Primary keys required**: CTP auto-adds them if missing from test cases
- **Master/slave comparison**: Results compared between master and slave dumps
- **Same architecture**: deploy/dispatch/impl pattern like shell/ and isolation/
